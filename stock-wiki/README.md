# 股票入門 LLM Wiki

主題：**新手看懂股票——基本概念與台股入門**

這是一個用「先討論、後生成」方式建立的 LLM Wiki，目的是當作知識庫，產生一份給完全不懂股票的人看的教學型 HTML 簡報。本 Wiki 僅作教育用途，不提供任何買賣建議或個股推薦。

## 從哪裡開始看
- [index.md](index.md)：所有頁面的目錄與 ingest 進度
- [schema.md](schema.md)：Wiki 的規則與格式
- [log.md](log.md)：每次 ingest 的紀錄與發現的問題

## 使用規則
- 每個事實都標註來源編號，例如 [s01]。
- 【作者觀點】：來源作者的主張，不是通用定論。
- 【待確認】：尚未被官方來源核對，或來源之間有衝突。
- 【待補】：目前沒有任何來源，不憑記憶補寫。
- 來源衝突時，官方來源優先於個人部落格與媒體。
