# Stock Wiki｜股票知識 Wiki

這是一個以股票與金融市場為主題的知識整理專案，目標是透過系統化的資料蒐集、分類與整理，建立適合初學者閱讀的股票知識庫。

## 專案目的

希望將原本較為零散的股票資訊整理成容易理解的內容，讓沒有投資經驗的人也能逐步認識股票市場，理解基本交易制度、投資報酬及相關風險。

## 知識架構

| 分類 | 內容 |
|---|---|
| 股票基礎 | 股票定義、股東權益及公司籌資 |
| 市場與交易 | 股票市場、交易時間、交易單位及交割制度 |
| 股價形成 | 買賣委託、價格優先及時間優先 |
| 投資報酬 | 資本利得、現金股利、股票股利及除權息 |
| 財務分析 | 財務報表、EPS、本益比、ROE、ROA及殖利率 |
| 投資工具 | 個股與 ETF 的差異 |
| 投資風險 | 系統性風險、非系統性風險及風險管理 |
| 常見迷思 | 股票投資常見錯誤觀念與認知 |

## 專案特色

- **系統化整理：** 將股票知識依照主題分類，建立清楚的學習架構。
- **初學者導向：** 使用簡單易懂的文字與實際例子解釋專業名詞。
- **資料來源整理：** 參考金融相關網站及官方機構資料，並記錄來源。
- **持續更新：** 隨著資料蒐集與學習進度，逐步補充及修正知識內容。

## 專案檔案

- `README.md`：專案介紹與知識架構。
- `index.md`：知識庫目錄與資料索引。
- `log.md`：專案更新紀錄。
- `concepts/`：股票相關概念與主題文章。

## 學習對象

適合對股票市場有興趣，但尚未具備金融或投資基礎知識的初學者。

## 注意事項

本專案僅作為金融知識整理與教育用途，不構成任何投資建議。投資前應自行研究相關資訊，並審慎評估風險。
